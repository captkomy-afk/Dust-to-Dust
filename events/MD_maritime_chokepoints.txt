# Delayed wargoal grant for a FULL chokepoint closure (MD_<canal>_close_canal /
# MD_<canal>_close_strait / PER_block_hormuz). Scheduled from each of those decisions'
# complete_effect via `country_event = { id = MD_maritime_chokepoints.2 days = 10 }`, fired on
# the closing country's own scope (so ROOT = the closer throughout). Same 10-day grace period
# as MD_maritime_chokepoints.1 to allow exemptions first. Three groups can end up with a
# wargoal against the closer, all re-checked fresh at fire time and all skipped for anyone
# exempted or for the closer itself:
#  1. Any other current co-controller of the chokepoint (didn't consent to a unilateral closure
#     of a strait they also border).
#  2. Countries in that chokepoint's regional "who actually gets cut off" list. Suez and Panama
#     don't get one - as pure interoceanic shortcuts (not regional straits) only major powers
#     are assumed to care enough to react.
#  3. Any Superpower (has_idea = super_power) or Regional Power (has_idea = regional_power),
#     everywhere, regardless of geography - closing an international chokepoint draws great
#     power attention no matter where it is.
